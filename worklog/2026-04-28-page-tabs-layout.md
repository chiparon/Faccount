# 2026-04-28 page tabs layout

## 目标
- 用户查看页面后反馈内容拥挤，需要拆成可切换的多页视图。

## 实际修改
- 重写 `frontend/src/App.vue` 的主布局。
- 新增顶部页内分页标签：
  - 流水
  - 记一笔/编辑
  - 月度总览
  - 预算流转
  - 账单导入
  - Trash
  - 基础管理
- 账户与分类从常驻右侧栏移入“基础管理”分页。
- 所有功能页使用 `v-show` 保持挂载，避免流水列表点击编辑时表单页面丢失事件。
- 监听 `transaction-edit-requested` 事件，编辑流水时自动切换到“记一笔/编辑”分页。
- 更新 `frontend/src/styles/main.css`，新增分页导航、页面容器和基础管理双栏布局样式。
- 顺手修复首页文案乱码。
